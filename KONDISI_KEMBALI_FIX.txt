KONDISI_KEMBALI BIND_PARAM TYPE FIX
===================================

STATUS: ✓ FIXED & VERIFIED

ERROR YANG TERJADI:
===================

"Return Request Failed: Data truncated for column 'kondisi_kembali' at row 1"

Terjadi saat user submit return request dengan barang yang memiliki riwayat pengembalian sebelumnya.

ROOT CAUSE:
===========

File: /opt/lampp/htdocs/PROJECT/api/peminjaman/return.php
Line: 161 (sebelum fix)

SEBELUMNYA (SALAH):
    $insd->bind_param("iiiiii", $pengembalian_id, $barang_id, $jumlah_kembali, 
                      $kondisi_kembali, $jumlah_rusak, $sisa_dikembalikan);
                      ^^^^^^
                      ALL INTEGER - WRONG!

MASALAH:
- Column 'kondisi_kembali' adalah ENUM('Baik','Rusak')
- ENUM adalah tipe STRING, bukan INTEGER
- bind_param signature "iiiiii" berarti semua parameter adalah INT
- PHP coerce string 'Baik'/'Rusak' menjadi integer → 0
- Database menolak value yang tidak valid untuk enum ('Baik' atau 'Rusak')
- Hasilnya: "Data truncated" error

SOLUSI:
=======

SESUDAH (BENAR):
    $insd->bind_param("iiisii", $pengembalian_id, $barang_id, $jumlah_kembali,
                      $kondisi_kembali, $jumlah_rusak, $sisa_dikembalikan);
                      ^^^^^^
                      4th parameter adalah S (STRING) - CORRECT!

PENJELASAN SIGNATURE "iiisii":
- i (pengembalian_id) → INT
- i (barang_id) → INT
- i (jumlah_kembali) → INT
- s (kondisi_kembali) → STRING ← FIX: Was 'i', now 's'
- i (jumlah_rusak) → INT
- i (sisa_dikembalikan) → INT

LOGIC YANG BENAR:
=================

$kondisi_kembali = 'Baik';  // Default STRING value

if ($jumlah_rusak > 0) {
    $kondisi_kembali = 'Rusak';  // Update to STRING value
}

Kedua nilai adalah STRING, jadi bind_param harus 's' bukan 'i'.

DATABASE COLUMN:
================

kondisi_kembali enum('Baik','Rusak') NOT NULL

- Type: ENUM
- Valid values: 'Baik', 'Rusak'
- Default: 'Baik'

Hanya menerima STRING values seperti 'Baik' atau 'Rusak'.
Tidak boleh nilai integer atau value lain.

- VARCHAR/CHAR/TEXT/ENUM → 's'
