# Fix: Status Enum Error in Return/Inspection Process

## Problem Identified

**Error Message:** `Data truncated for column 'status' at row 1`

**When it occurs:** After user extends (perpanjang) their loan and submits a return, when admin/PIC tries to inspect and finalize the return.

**Root Cause:** The `api/pengembalian/inspect.php` file was trying to set `peminjaman.status` to invalid enum values:
- ❌ `'Semua Rusak'` (NOT in enum)
- ❌ `'Sebagian Dikembalikan'` (NOT in enum)

These values don't exist in the database enum definition for `peminjaman.status`.

---

## Solution Implemented

### File Modified
- `api/pengembalian/inspect.php` (Lines 173-194)

### Changes Made

**Old Code (WRONG):**
```php
if ($sisa <= 0 && $total_items > 0) {
    // All items returned
    if ($total_damaged > 0) {
        $final_status = ($total_damaged >= $total_items) ? 'Semua Rusak' : 'Dikembalikan';
    } else {
        $final_status = 'Dikembalikan';
    }
} else if ($total_returned > 0) {
    // Partial return
    $final_status = 'Sebagian Dikembalikan';  // ❌ NOT IN ENUM!
}
```

**New Code (FIXED):**
```php
if ($sisa <= 0 && $total_items > 0) {
    // All items returned - use valid enum value
    $final_status = 'Dikembalikan';
} else if ($total_returned > 0) {
    // Partial return - use valid enum value
    $final_status = 'Proses Return';
}
```
