STATUS DISPLAY MISMATCH FIX
==========================

MASALAH YANG DIHADAPI:
=====================

User melihat peminjaman dengan status "Sebagian Dikembalikan" di list,
tapi saat klik Return dan submit, error muncul:
"Status saat ini: Dikembalikan"

Padahal user yakin dia pilih "Sebagian Dikembalikan", bukan "Dikembalikan".

AKAR PENYEBAB:
==============

1. DATABASE STATUS (ACTUAL)
   Tabel peminjaman punya enum dengan nilai:
   - 'Menunggu Persetujuan'
   - 'Disetujui'  
   - 'Ditolak'
   - 'Sedang Dipinjam'
   - 'Dikembalikan'        ← Status sebenarnya di database
   - 'Proses Return'
   
   TIDAK ADA 'Sebagian Dikembalikan' sebagai enum value!

2. DISPLAY STATUS (TRANSFORMED)
   API get_all.php melakukan transformasi status untuk UI:
   - Jika ada pengembalian pending (status 'Diajukan' atau 'Dicek')
   - Dan total items yang dikembalikan < total items dipinjam
   - MAKA tampilkan status sebagai: "Sebagian Dikembalikan"
   
   Ini adalah status "buatan" untuk display saja!

3. API VALIDATION ERROR
   return.php memvalidasi status langsung dari database:
   - Sebelumnya: hanya accept ['Sedang Dipinjam', 'Sebagian Dikembalikan', 'Proses Return']
   - Masalah: 'Sebagian Dikembalikan' TIDAK ada di database!
   - Hasil: Error 400 - status tidak valid

ALUR TERJADINYA BUG:
====================

1. User punya peminjaman di database dengan status = 'Dikembalikan'
2. Ada pengembalian pending (status 'Diajukan'/'Dicek') dengan items 2 dari 3
3. get_all.php lihat: total_kembali < total_items
4. get_all.php transform dan tampilkan: status = "Sebagian Dikembalikan"
5. User lihat status "Sebagian Dikembalikan" di list
6. User klik Return button
7. Modal terbuka dan load detail
8. User isi dan klik Submit
9. return.php query database: SELECT status FROM peminjaman WHERE id = ?
10. Database return: status = 'Dikembalikan' (bukan "Sebagian Dikembalikan")
11. return.php check: 'Dikembalikan' not in ['Sedang Dipinjam', 'Sebagian Dikembalikan', 'Proses Return']
12. ERROR! Respond dengan error message

SOLUSI YANG DITERAPKAN:
======================

File: /opt/lampp/htdocs/PROJECT/api/peminjaman/return.php

SEBELUMNYA (LINE 70):
    $allowedStatuses = ['Sedang Dipinjam', 'Sebagian Dikembalikan', 'Proses Return'];
    
SEKARANG (FIXED):
    $allowedStatuses = ['Sedang Dipinjam', 'Dikembalikan', 'Proses Return'];
    // Note: 'Dikembalikan' is allowed if there are still items pending return

ALASAN:
- 'Sebagian Dikembalikan' TIDAK PERNAH menjadi status di database
- Status di database hanya: Sedang Dipinjam, Dikembalikan, Proses Return
- Status display "Sebagian Dikembalikan" adalah auto-generated oleh get_all.php
- return.php HARUS accept status yang sebenarnya ada di database

ATURAN STATUS DATABASE:
=======================

Sedang Dipinjam       = Barang masih dipinjam, belum ada return request
Proses Return        = User sudah submit return request, menunggu PIC check
Dikembalikan         = Sudah dikembalikan atau sebagian sudah dikembalikan

Note: Status 'Dikembalikan' di database bisa berarti:
  - Fully returned (semua items kembali)
  - Partially returned (sebagian items kembali, sebagian masih dibawa)
  
Detail real (full/partial) dilihat dari tabel pengembalian,
bukan dari status field peminjaman.
