11. TROUBLESHOOTING QUICK REFERENCE
================================================================================

Problem: "Database connection failed"
  Solution: Check api/koneksi.php has correct credentials
  Check: Database 'peminjaman' exists
  Check: Root user can access database

Problem: "API returns empty array"
  Solution: Check if data exists in database table
  Check: User has correct role to access endpoint
  Try: Test API directly in browser URL bar

Problem: "Page shows 'Data not found'"
  Solution: Check if record exists in database
  Try: Use valid peminjaman ID or kode
  Check: Browser console for API error details

Problem: "User cannot see page (redirected to login)"
  Solution: Check user's role in database
  Check: Role matches required role for page
  Try: Login as admin to test access

Problem: "Data takes too long to load"
  Solution: Check API query time in browser Network tab
  Try: Test with smaller dataset first
  Check: Database indexes exist on key fields

Problem: "JavaScript errors in console"
  Solution: Press F12 to open developer tools
  Check: Check 'Console' tab for red error messages
  Look: For undefined variables or missing functions
  Check: escapeHtml() function exists in page

Problem: "Changes don't appear after saving"
  Solution: Clear browser cache (Ctrl+Shift+Delete)
  Try: Hard refresh (Ctrl+F5)
  Check: Database record actually updated
  Check: API returns new data
