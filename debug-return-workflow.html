Return Workflow Status Verification

Return Status States

Diajukan - User submitted return, waiting for PIC inspection
pengembalian.status = 'Diajukan'
Dicek - PIC opened the inspection modal
pengembalian.status = 'Dicek'
Selesai - PIC clicked "Finalize" and inspection is done
pengembalian.status = 'Selesai'

PIC List Display Logic

Current filter: status = 'Diajukan' ONLY

This means PIC sees:

  • ✅ Diajukan - New submissions waiting for inspection
  • ❌ Dicek - Submissions being examined (PIC already has them)
  • ❌ Selesai - Finalized submissions (inspection done)

Expected Behavior

  1. PIC sees list of new returns (status='Diajukan')
  2. PIC clicks "INSPECT" button → Return goes to 'Dicek' → DISAPPEARS from list
  3. Modal opens with inspection form
  4. PIC clicks "FINALIZE" → Status changes to 'Selesai' → Inspection complete
  5. Modal closes, list refreshes
  6. Return should NOT appear in list anymore

Troubleshooting

If finalized returns still appear, it means:

  • Return status is still 'Diajukan' or 'Dicek' (finalization failed)
  • OR the JavaScript list doesn't refresh after finalization
  • OR there are multiple returns for same user and one is finalized while another is pending
