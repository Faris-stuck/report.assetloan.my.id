# 🎯 QUICK REFERENCE: Tombol EXTEND - Solusi Komprehensif

## Masalah
```
Tombol EXTEND tidak muncul untuk peminjaman yang belum pernah extend
```

## Root Cause
Backend tidak mengirim field `can_extend` ke frontend.  
Frontend hanya menampilkan tombol jika ada data di `extend_peminjaman`.

## Solusi

### Backend `/api/peminjaman/get_all.php`
```php
// Hitung can_extend dari peminjaman.status
$final_statuses = ['Dikembalikan', 'Returned', 'Completed', 'Closed', 'Rejected', 'Ditolak', 'Batal'];
$can_extend = !in_array($row['status'], $final_statuses);

// Kirim ke frontend
'can_extend' => $can_extend
```

### Frontend `/user/pengembalian/ajukan-pengembalian.html`

**1. Render tombol dengan visibility dari can_extend:**
```javascript
const extendButtonDisplay = p.can_extend ? 'inline-block' : 'none';
style="display: ${extendButtonDisplay};"
```

**2. loadExtendStatus() hanya untuk display badge:**
```javascript
// Hanya display badge status extend
// Jangan touch button visibility (sudah diset dari can_extend)
if (badgeEl && res.has_extend && res.data) {
    // Show badge
}
```
