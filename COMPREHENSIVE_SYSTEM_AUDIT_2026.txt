   Pattern: SUM/COUNT across all pengembalian records per barang_id
   Query Template:
   ```sql
   SELECT 
     barang_id,
     SUM(jumlah_kembali) as total_kembali,
     SUM(jumlah_rusak) as total_rusak
   FROM detail_pengembalian
   WHERE pengembalian_id IN (
     SELECT id FROM pengembalian WHERE peminjaman_id = ?
   )
   GROUP BY barang_id
   ```
   Impact: Correctly sums across multiple submission batches ✓
