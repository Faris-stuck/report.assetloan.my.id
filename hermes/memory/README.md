# Memory Folder

Folder ini berisi layer memory Hermes.

Isi utama:
- `conversation-helper.php` untuk pengolahan mode/jawaban/provider response
- `memory-helper.php` untuk memory context, fallback file, search, dan backfill ke database

Kalau ingin ubah cara Hermes mengingat percakapan atau membangun memory context, mulai dari folder ini.
