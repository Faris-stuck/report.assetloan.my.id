# Config Folder

Folder ini berisi konfigurasi Hermes yang utama dan tematik:
- `ai_agent.php` untuk model, provider, timeout, fallback provider, dan runtime AI Hermes
- schema tabel dan scope
- role dan permission
- keyword deteksi konteks
- limit dan magic number
- string tampilan

Kalau ingin ubah model Hermes atau perilaku statisnya tanpa mengubah engine utama, mulai dari folder ini.
